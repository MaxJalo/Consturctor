# Заказ · Комитет

Скилл отвечает на вопрос «что нужно сделать по этому заказу» для роли `committee`.

## Ответ

Три коротких блока:

- Уже сделано
- Сделать сейчас
- Блокирует переход

Черновик базовой версии и условий — `external_order.case(action="propose", role="committee", order_id=...)` (`baseline_proposal`). Факт только после «Принять». Решение Комитета не подменяй и историю не удаляй.

## Зона службы

Сводка готовности пакета и заключений служб, проект решения, условия и базовая версия. Протокол совещания готовит отдельный скилл «Протокол».

Дальше по пути: пакет заключений, решение, протокол и базовая версия. После решения ТКП выпускает производство по скиллу «ТКП».

## Конец ответа

Последняя строка — `[[turn-done]]`. Если писать нечего, ответь «Готово.» и маркер. Стадию не переводи.
