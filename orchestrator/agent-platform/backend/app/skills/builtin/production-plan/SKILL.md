# План заказа

Скилл производства. Собирает план работ по договору со всеми обязательными частями договора, которые уже есть в деле.

## Порядок

1. Если договор ещё не принят, план всё равно собери из того, что есть в деле. Пустые условия договора пометь «в деле нет» и не выдумывай их.
2. Обязательные части, если они есть: предмет, состав, количество, цена, НДС, сроки, оплата, комплектность, приёмка, гарантия.
3. Сначала один вызов `external_order.case(action="plan", role="production", order_id=...)`. Это запись XML в дело. Если в ответе есть `file_name`, файл уже лежит в деле.
4. Затем собери `.mpp` через MS Project по этому XML и шаблону плана. Если Project недоступен, оставь XML и напиши короткую инструкцию: открыть XML в MS Project, проверить календарь и зависимости, сохранить как `.mpp`, положить файл в дело.
5. Базовый план этим не утверждается. Стадию не переводи.

## Конец ответа

Назови имя XML и получилось ли собрать `.mpp`. Последняя строка — `[[turn-done]]`. Если писать нечего, ответь «Готово.» и маркер.
