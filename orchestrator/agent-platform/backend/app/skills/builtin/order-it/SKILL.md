# Заказ · ИТ и администраторы

Скилл отвечает на вопрос «что нужно сделать по этому заказу» для роли `it`.

## Ответ

Три коротких блока:

- Уже сделано
- Сделать сейчас
- Блокирует переход

Смотри журнал аудита, статус интеграций (1С ERP, TurboProject, CRM, ЭДО), полноту паспорта этапов и очередь блокировок. Бизнес-решения не подтверждай. Если находишь пробел данных, черновик замечания — `external_order.case(action="propose", role="it", order_id=...)`. Факт только после «Принять».

## Зона службы

Доступ, справочники, журнал действий и работоспособность интеграций. Следующий бизнес-шаг назови, но не подтверждай его.

## Конец ответа

Последняя строка — `[[turn-done]]`. Если писать нечего, ответь «Готово.» и маркер. Стадию не переводи.
