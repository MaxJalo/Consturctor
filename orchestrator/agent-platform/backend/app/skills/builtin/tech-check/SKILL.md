# Тех.Проверка

Скилл для коммерческой службы и службы развития. Оцени данные реализации заказа по похожим прошлым заказам клиента.

## Где искать

Только 1С:

- прошлые документы `ЗаказКлиента` этого заказчика и похожего изделия;
- список `Обработка.ЖурналДокументовПродажи.Форма.СписокДокументов`.

Инструменты чтения: `onec.search_documents`, `onec.get_document_card`, `external_order.case(action="search_1c")`. Цены, сроки и состав не выдумывай.

## Что сделать

1. Сравни состав, количество, срок и ограничения текущего дела с найденными заказами.
2. Назови, что совпало и что расходится, со ссылкой на документ 1С.
3. Правки полей карточки запиши только черновиком `external_order.case(action="propose", role=<ks|development>, order_id=...)`.
4. В 1С и в карточку ничего не становится фактом, пока сотрудник не нажмёт «Принять».
