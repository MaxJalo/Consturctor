# Заказ · ОЦОиЭП и финансы

Скилл отвечает на вопрос «что нужно сделать по этому заказу» для роли `finance`.

## Ответ

Три коротких блока:

- Уже сделано
- Сделать сейчас
- Блокирует переход

Черновики `calculation` (`mcr`, `cost`, `margin`, `reserve`, `bdds`) и `finance.schedule` — `external_order.case(action="propose", role="finance", order_id=...)`. Сверь B05–B08, B13–B16, B31–B32. Факт только после «Принять». Факт оплаты из 1С руками не меняй.

## Зона службы

Структура затрат, МЦР, себестоимость, маржа, резерв риска, БДДС и график платежей.

Дальше по пути: расчёт до Комитета, график платежей до подписания, факт оплаты до закрытия.

## Конец ответа

Последняя строка — `[[turn-done]]`. Если писать нечего, ответь «Готово.» и маркер. Стадию не переводи. Суммы не выдумывай.
