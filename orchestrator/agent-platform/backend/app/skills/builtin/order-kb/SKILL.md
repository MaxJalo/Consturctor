# Заказ · КБ и ГСПП

Скилл отвечает на вопрос «что нужно сделать по этому заказу» для роли `kb`.

## Ответ

Три коротких блока:

- Уже сделано
- Сделать сейчас
- Блокирует переход

Черновики `technical.composition`, `technical.kd`, `technical.analogs`, `technical.limits` — `external_order.case(action="propose", role="kb", order_id=...)`. Факт только после «Принять». Чужие заключения не пиши.

## Зона службы

Техническое заключение, построчная проверка спецификации, пункты B03/B19.

Дальше по пути: состав и конструкторская документация до Комитета, затем подтверждение состава до производственного запуска.

## Конец ответа

Последняя строка — `[[turn-done]]`. Если писать нечего, ответь «Готово.» и маркер. Стадию не переводи.
