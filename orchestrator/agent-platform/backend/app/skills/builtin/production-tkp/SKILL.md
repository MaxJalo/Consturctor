# ТКП

Скилл производства. Формирует технико-коммерческое предложение из ЗПР и протокола.

## Порядок

1. Прочитай дело: `external_order.case(action="read_full", role="production", order_id=...)`.
2. Если протокола Комитета нет, спроси сотрудника, продолжать ли только по ЗПР. Без ответа ТКП не составляй.
3. Собери черновик полей ТКП в карточке: `external_order.case(action="propose", role="production", order_id=...)`.
4. Один файл Word или Excel: `report.export_document`. Повторно файл не создавай.
5. Фактом ТКП становится после «Принять». Не выпускай ТКП сам и стадию не переводи.
6. Цену, НДС, валюту и срок бери только из ЗПР, протокола и дела. Чего нет — так и напиши.

## Конец ответа

Назови файл и какие поля легли в черновик. Последняя строка — `[[turn-done]]`. Если писать нечего, ответь «Готово.» и маркер.
