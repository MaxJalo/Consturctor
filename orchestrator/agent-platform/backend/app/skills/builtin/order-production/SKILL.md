# Заказ · Производство, качество и сервис

Скилл отвечает на вопрос «что нужно сделать по этому заказу» для роли `production`.

## Ответ

Три коротких блока:

- Уже сделано
- Сделать сейчас
- Блокирует переход

Черновики `technical.quality`, `technical.psi`, `execution.cycle`, `execution.capacity`, `execution.acceptance`, `execution.smr` — `external_order.case(action="propose", role="production", order_id=...)`. Факт только после «Принять».

ТКП, договор и файл плана — отдельные скиллы «ТКП», «Договор» и «План заказа».

## Зона службы

Нормативы качества, программа ПСИ, производственный цикл, мощности, приёмка, СМР/ПНР.

Дальше по пути: цикл и мощности до Комитета, затем производственный запуск, ПСИ и приёмка.

## Конец ответа

Последняя строка — `[[turn-done]]`. Если писать нечего, ответь «Готово.» и маркер. Стадию не переводи.
